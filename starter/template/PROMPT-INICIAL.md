# Prompts para empezar

Abre Claude Code dentro de la carpeta del proyecto (`claude`) y pega uno de estos.

## Web para Financore Solutions

```
Construye una landing para Financore Solutions usando las skills estilo-financore y financore-brand.

- Secciones: navegación fija, hero con título y dos botones, [SECCIONES QUE QUIERAS], contacto y footer.
- Incluye herramientas interactivas: [por ejemplo: simulador de préstamo con sliders, test de preparación para crédito].
- Animaciones con Motion (motion/react): entradas al hacer scroll y hover suaves.
- Mobile-first y totalmente responsive.

Empieza por la estructura del proyecto y después construye sección por sección. Muéstrame cada sección antes de pasar a la siguiente.
```

## Web para cualquier otro negocio

```
Construye una landing moderna para [TU NEGOCIO / PRODUCTO].

Requisitos:
- Tailwind CSS para los estilos y Motion (motion/react) para todas las animaciones.
- Sigue los tokens de diseño de la skill frontend-design.
- Secciones: navegación fija, hero con título y CTA, 3 beneficios, prueba social, precios, preguntas frecuentes y footer.
- Mobile-first, totalmente responsive, Lighthouse de rendimiento 90+.

Empieza por la estructura y construye sección por sección. Muéstrame cada sección antes de seguir.
```
