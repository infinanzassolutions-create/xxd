Why this works

Set up the environment before you write a prompt.

You don't need a designer or a dev team. Claude Code is only as good as the environment, animation library, design rules, and components it can work with. This stack turns it from a generic code generator into something closer to a senior web designer.

01

Step 1

Install Claude Code

Claude Code runs on your machine, in your terminal. The native installer is the recommended route:

curl -fsSL https://claude.ai/install.sh | bash

Or install it with npm (requires Node.js 18+):

npm install -g @anthropic-ai/claude-code

Then start it from your project folder and sign in with your Claude account when prompted:

claude

Why it matters: Claude Code reads your whole project, edits several files at once, runs commands, and iterates on the result. Copying code out of a chat window can't do that.

02

Step 2

Add animation support with Motion

Default AI-generated sites look static. Motion is the biggest single upgrade toward a site that feels premium. Install it inside your React or Next.js project:

npm install motion
Note: Framer Motion is now published as motion. Import it from motion/react. The old framer-motion package still works if your project already uses it.

Then add this to your project's CLAUDE.md so it applies to every session:

"Use Motion (motion/react) for all animations. Apply scroll-triggered fades, staggered reveals, and smooth hover transitions on interactive elements. Respect prefers-reduced-motion."

What changes: hero sections gain movement, cards slide in on scroll, and buttons respond to hover. This is a large part of what separates an "AI website" from an agency website.

03

Step 3

Add a design-focused skill

Skills are reusable instruction sets that Claude Code loads when a task calls for them. A frontend design skill gives Claude taste: spacing, hierarchy, typography, color, and layout rules.

  1. Create a folder for the skill: .claude/skills/frontend-design/
  2. Add a SKILL.md inside it with a name and description in the frontmatter, followed by your design rules
  3. Claude Code uses the description to decide when to load it. You can also call it by name with /frontend-design
---
name: frontend-design
description: Design system and taste rules. Use when building any UI.
---

# Frontend design rules
- Type scale: 12 / 14 / 16 / 20 / 28 / 40 / hero clamp
- Spacing: 8px grid (4, 8, 16, 24, 32, 48, 64, 96)
- Colors: tokens only (bg, surface, text, muted, accent)
- Buttons: hover, focus-visible, active, disabled states
- Avoid the generic AI look: no purple gradients, no emoji icons

What to include:

  • A typography scale: a real type system instead of random font sizes
  • A spacing system on an 8px base grid
  • Color tokens (primary, neutral, accent) instead of loose hex codes
  • Component patterns: button states, card structure, form layouts
  • Explicit "avoid the generic AI aesthetic" rules

Why it matters: without a design skill, Claude Code falls back on generic Tailwind patterns. With one, every component follows the same design system, which is the part agencies charge $10K to build.

04

Step 4

Integrate a component library (21st.dev)

21st.dev is a library of production-ready components you can drop into a React project.

  1. Visit 21st.dev
  2. Browse components: heroes, pricing tables, testimonials, navbars, footers
  3. Copy the component code, or use the install command shown on the component page
  4. Paste it into your project and ask Claude Code to integrate it

Prompt to use:

"Integrate this 21st.dev component into our landing page. Match it to our design tokens, replace the placeholder content with our copy, and add Motion entrance animations."

Why it matters: the components are already designed by professionals, and Claude Code adapts them to your brand. You skip most of the design work and still end up with a site that looks expensive.

Common mistakes

What sinks most first attempts.

Skipping the design skill

Without it you get a generic site that looks AI-generated.

Vague prompts

Be specific about sections, animations, and content. Claude Code is only as good as your brief.

Not iterating

The first output is rarely the final one. Ask Claude Code to refine spacing, contrast, and motion.

Forgetting performance

Ask for lazy-loaded images, optimized fonts, and a Lighthouse audit at the end.
